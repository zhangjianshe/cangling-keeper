# 建筑材质开发计划与验证

## 第一轮：模型自带基础颜色贴图（已实现）

普通 GLB 与 3D Tiles 的 GLB/b3dm 内容共用 ModelLayerRenderer：

- 读取嵌入图片、材质引用的 TEXCOORD 集合；纹理存在但对应 UV 缺失时明确报错。
- 尊重 glTF 的 Repeat / MirroredRepeat / ClampToEdge，以及放大、缩小和 mipmap 过滤设置。
- 基础颜色纹理以 sRGB 纹理上传；baseColorFactor 在线性空间由着色器相乘。无贴图采用白色 1×1 纹理与颜色系数。
- 在线性、预乘透明度空间生成完整 mipmap，降低远处重复纹理的闪烁及透明边缘黑边。
- 小纹理保持原尺寸，仅大于 2048 的图片缩小。修复旧 thumbnail 调用把小图放大，造成纹理预算虚增的问题。
- 保留单图解码尺寸、单模型纹理预算及整体模型缓存预算，估算包含 mipmap 开销。

当前范围是自包含 GLB 内嵌 PNG/JPEG 等图片。外部图片 URI 不会自动下载；KTX2/Basis、纹理变换扩展、完整 glTF Alpha 与扩展材质仍未支持。

验证资产为原创 `assets/textured-building.glb`，可运行源归档中的 `scripts/build-textured-building.py` 重建：四面墙使用重复窗格，屋顶使用纯色材质。

自动验证：142 项 Earth 测试通过，2 项需要外部条件的测试默认跳过；另外指定该资产执行 `upload_native_model -- --ignored`，GPU 绘制通过。测试覆盖 UV、采样方式、颜色系数、线性 mipmap 和奇数尺寸。浏览器使用 WebGL2 检查立面纹理和无贴图屋顶。

## 第二轮：郑州建筑程序化外观（已实现）

近景墙面按边长与高度生成重复窗格 UV，屋顶独立纯色材质。485 个建筑、三级几何与高度保持不变，本机独立发布 `zhengzhou-cbd-textured`，原数据集不变。浏览器近景绘制 23 个可见叶节点，拉远到 18 km 后绘制 1 个 low 模型；pending=0、errors=[]、budgetLimited=false。450 m 高度近距离可见窗格。该外观是程序化生成，不是真实立面照片。

## 第三轮：材质质量与资源优化（基础 PBR 已实现）

已按完整像素和尺寸复用同一渲染器内的 GPU 纹理，跨 primitive 和瓦片共享；采样器和颜色系数仍各自独立。使用弱引用索引，最后一个模型移除后清理纹理及缓存键；预算保守按每份资源计入 CPU 键和 GPU mipmap 开销。GPU 回归验证重复模型不增加纹理数量、清空场景释放缓存。各级 LOD 均使用相同立面纹理，避免子瓦片加载时回退为灰色。

法线、粗糙度/金属度贴图及系数已接入，见下方本轮说明。

## 小角度旋转灰闪修复

根因是视野外资源每次 tick 立即卸载，视角旋回时需重载子瓦片；REPLACE 在子瓦片未齐时切回父级，而父级此前使用纯色材质。

- 最近离开视野的 Ready 资源保留 20 tick（约 5 秒），不参与绘制；缓存最多 32 份，优先给当前选择及待加载资源预留容量。隐藏图层立即释放。
- LOD 按正常 SSE 阈值细化，已细化的节点直到 SSE 降至阈值的 75% 才降级，减少临界抖动。
- 缓存淘汰后重置重试计数，避免正常视角切换耗尽后续网络重试机会。
- 郑州三个 LOD 均内嵌同一张立面纹理，仍共享 GPU 纹理；几何精度和瓦片树保持不变。

145 项 Earth 测试通过，覆盖旋回复用、缓存过期、容量约束、图层隐藏和阈值滞回。首次进入尚未加载的区域仍可能显示粗几何，但不再由纯色父级造成灰色闪烁。

## 基础 PBR 材质

依据 [glTF 2.0 材质规范](https://registry.khronos.org/glTF/specs/2.0/glTF-2.0.html)：

- 基础颜色图使用 sRGB；法线图与 metallicRoughness 图使用线性格式。缓存键包含颜色空间，同样像素不会错误复用不同格式的 GPU 纹理。
- 三类贴图各自读取 texCoord 和 sampler，支持不同 UV 集合；引用不存在的 UV 明确报错。三类图片共同计入原有纹理预算。
- normalTexture.scale 控制 XY 分量强度。法线图在片元中通过几何位置和该贴图 UV 的导数建立切线基，处理镜像 UV；退化 UV 或无贴图时使用几何法线。当前不使用文件中的 TANGENT，也不保证与离线 MikkTSpace 烘焙逐像素一致。
- metallicRoughness 图的 G 为粗糙度、B 为金属度，与材质系数相乘；没有图片时保留材质系数。
- 直接光使用 GGX 分布、Schlick Fresnel 与几何遮蔽近似，配简单环境填充；粗糙度在着色器中设置最小值以避免尖锐高光数值不稳定。
- 数据纹理的 mipmap 不做 sRGB 或预乘透明度转换；法线采样后重新归一化。没有增加模型顶点或修改碰撞体。

范围限制：没有 IBL 环境贴图、实时阴影、玻璃透射/折射、AO、发光材质及完整透明排序；这不是完整 glTF 材质扩展实现。

原创测试模型 `assets/pbr-building.glb` 由 `scripts/build-pbr-building.py` 生成，包含独立法线 UV、可对照的凹凸条纹、窗面/墙面粗糙度及金属屋顶。148 项测试通过；PBR 测试模型和郑州真实瓦片分别通过 GPU 上传/绘制测试；浏览器 WebGL2 法线开关对照通过。

郑州 `zhengzhou-cbd-textured` 的三个 LOD 均加入同样的窗框法线和粗糙度图，保持前一轮各级外观一致的处理。
