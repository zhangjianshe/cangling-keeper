# 智能体回复时间线（第一轮）

## 展示与存储

新回复按模型轮次展示：执行说明 → 本轮实际工具记录 → 下一轮说明 → 工具 → 最终答复。
工具保持默认折叠和原有审批、详情、停止行为；技能准备记录仍在折叠摘要中。
简单问答无需工具或强制计划。模型只输出简短操作意图和进展，不要求展示内部推理。

原始合并正文仍保存在 agent_messages.content，供模型历史、搜索和导出使用。
model_metadata.presentation 保存 version=1、sequence 和 segments（step、start、kind）。start 是 UTF-16 偏移，与浏览器字符串切片一致；下一段 start 是上一段终点。没有重复保存正文，也没有新增数据库表。
正文和 presentation 在同一 SQLite UPDATE 中保存，随后通过原流事件发布；工具使用现有 responseId + step 关联。实时更新按 sequence 拒绝过期内容，包括证据校验撤回较长草稿的情况。

只有正常结束、无工具调用且通过现有证据检查的最后一轮标记 final。等待审批、停止、失败或服务中断的未完成文字保留 commentary，不伪装成最终答复。最终答复不意味着用户目标已达成，执行证据规则保持不变。

## 兼容性

旧回复没有真实轮次边界，维持原展示方式，不猜测顺序。无效或越界的布局元数据回退完整正文。
每个回复版本各有布局；刷新和重启从 SQLite 恢复。备份沿用原 metadata 与工具 step 保存机制，不自动重放任何操作。

## 本机验证

- 模拟模型 HTTP：多轮中文及 Emoji、真实工具 step、最终段标记、刷新、停止、重启后同回复ID恢复。
- 界面：交错 DOM 顺序、增量文字更新、过期流事件拒绝、草稿纠正、版本隔离及无效布局回退。
- 新布局下的审批差异/命令预览、输入框附近确认、停止时禁用审批均通过。
- 其余 ReAct 账户隔离、工具过程、传输恢复及账户界面回归通过。
- Chrome 隔离模拟服务：执行说明与三个工具按序展示，任务结束后最终答复出现，刷新后顺序与标记保留。未调用真实模型。

## 第二轮：任务推进与收尾

复杂任务使用 update_plan 保存可验证步骤；每轮运行时从当前会话、当前回复的成功调用中重新读取最新计划，加入 executionEvidence.latestPlan 和 remainingSteps。上下文压缩不丢失该进度。失败的计划更新不覆盖已有计划，受阻和跳过仍列为未完成，不自动改为完成。读取时重新校验计划结构和长度，不向系统提示词复制任意工具输出。

模型依据真实工具结果继续或调整方案，最终交代实际修改、验证结果和未完成事项；简单问答无需计划。此规则是模型行为约束，不是语义上的完成证明，goalStatus 仍为 not_assessed。工具成功、命令退出成功均不保证用户目标完成或测试全部通过。停止、审批、失败和预算限制沿用原有机制，不添加自动重试、额外轮次或权限。原始工具记录与计划保留于 SQLite，刷新可恢复。

验证覆盖最新计划恢复、同时间更新顺序、会话/回复隔离、失败更新、受阻及跳过原因、无效持久化数据，以及模拟模型请求中实际收到的计划和剩余步骤。

## 第三轮：剩余工作交接

终止回复的正文下方展示最新成功计划中的未完成步骤。进行中步骤标为“待核实”，跳过步骤保留原因但不加入继续草稿。准备继续只填充空输入框，触发原有草稿保存流程，由用户编辑并发送；不调用模型、不重放工具、不延续旧审批。模型进度仍不是执行认证。

运行中、历史预览、归档或回收站不可准备继续；切换会话或账户后旧按钮失效。计划来自当前回复版本的工具记录，刷新后重建，无新增数据库字段。无计划或全部完成时不显示。

## 第四轮：命令执行证据

本轮变更面板按实际 run_command 记录汇总六类结果，保留逐条完整输出。审批/执行状态及停止、中断、超时优先，只有 succeeded 且整数 exitCode=0 才列为正常退出；未知状态或缺少可靠退出码列为待核实。正常退出不认证测试断言、业务目标或模型总结。普通命令不自动识别为测试，不新增模型调用或数据库迁移。

专项回归：scripts/test-command-summary-ui.cjs，已加入 test-react-acceptance.py。

## 精简任务摘要

默认只展示一条任务状态与实际文件修改/命令数量摘要；失败、拒绝、停止/中断和预算临界提醒保留在折叠标题中。详细计划、文件差异及撤销、命令输出、证据统计与预算收纳到展开内容。正常结束且没有工具调用的普通问答隐藏执行摘要；原始记录继续保存。上下文显示估算占比，完整估算和实际 usage 保留在悬停提示中；压缩中及压缩异常仍直观显示，未知用量不伪装为零。
